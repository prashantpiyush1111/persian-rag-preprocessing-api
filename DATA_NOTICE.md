# Data and provenance

This public portfolio edition is adapted from internship project code.
The employer permits publication without company data. The private Git history,
internal deployment documentation, operational endpoints and original datasets
are not included in this repository.

All files under `examples/` were newly authored for this public edition. They
describe a fictional library and are not copied or anonymized company records.
Inline test fixtures are generic synthetic inputs. No production metrics are
claimed. Generated indexes, model caches and run outputs should remain local.

Maintained by [Ariana Zalnezhad](https://github.com/robbiinn).
The public edition adds documentation, synthetic examples and portability fixes
to the internship implementation. Publication permission does not by itself
grant a particular open-source license; no new license is assigned here.
